# Multi-AI Collaboration Protocol

## Source of truth
This repository is canonical once migration is complete. Until then, ChatGPT Sites remains production and this repository is the controlled migration source.

## Mandatory behavior
- Read README, PROJECT_CONSTITUTION, CHANGELOG, and relevant manifests before editing.
- Do not assume another AI's suggestion is correct.
- Preserve working features unless the task explicitly replaces them.
- Prefer small reversible changes.
- Never insert credentials, API keys, private user data, or secrets into repository files.
- Do not publish, delete, purchase, widen visibility, or connect sensitive accounts without explicit human approval.
- When changing course content, preserve learning progression and avoid turning the course into a prompt list.
- When changing design, preserve accessibility, readability, responsive behavior, and download functionality.

## Handoff format
1. What I inspected
2. What I changed/propose
3. Files/sections affected
4. Risks or uncertainties
5. Validation performed
6. Recommended next reviewer
